# Hail Cafe Platform

منصة مستقلة لمطعم وكافيه هيل في إربد سيتي سنتر، مبنية بـ Next.js/vinext
ومهيأة للنشر على OpenAI Sites.

## الأسطح

- `/` المنيو الرسمي، البحث، السلة، السفري، وجلسة الطاولة متعددة الجولات.
- `/ops` لوحة الإدارة والصالة والسفري والمنيو والمحتوى.
- `/kds` شاشة المطبخ.
- واجهات API دائمة للطلبات والجلسات وخدمة الطاولة وسجل الحالات.

## التشغيل

يتطلب Node.js `>=22.13.0`.

```bash
npm ci
npm run dev
npm run lint
npm test
```

تُحفظ البيانات في D1 والصور المرفوعة في R2. تولّد تغييرات المخطط عبر:

```bash
npm run db:generate
```

## إعداد الطاقم والأتمتة

انسخ `.env.example` إلى ملف بيئة محلي لا يُرفع إلى Git، واضبط عند الحاجة:

- `ADMIN_EMAILS`: قائمة بريدية مفصولة بفواصل لمديري النظام.
- `STAFF_ROLE_RULES`: كائن JSON يربط البريد بدور `manager` أو `kitchen` أو
  `floor`.
- `ORDER_WEBHOOK_URL`: وجهة اختيارية لأحداث الطلبات الجديدة.
- `ALERT_WEBHOOK_URL`: وجهة اختيارية لطلبات خدمة الطاولة.

لوحة الطاقم تستخدم Sign in with ChatGPT، ثم تفرض الصلاحيات مرة أخرى داخل كل
واجهة API. لا توجد أسرار داخل المصدر.

## البيانات الرسمية

القائمة والصور والأسعار مأخوذة من ملف المنيو الرسمي المرتبط من Linktree
الرسمي، وبيانات العنوان والهاتف والدوام من صفحة Google Maps الرسمية. الأسعار
المعروضة قبل ضريبة المبيعات 7% كما ينص المنيو الرسمي.
